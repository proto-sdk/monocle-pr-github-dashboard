Setup Instructions

To make this dashboard fully functional, you need to deploy the API proxy with your GitHub PAT:

Option 1: Deploy to Vercel (Recommended)

  1. Fork the repository to your GitHub account
  2. Sign up for a free Vercel account
  3. Import the serverless-api folder as a new project
  4. Add your GitHub PAT as an environment variable: GITHUB_PAT
  5. Deploy and get your API URL
  6. Update the dashboard to use your API endpoint

Option 2: Deploy to Netlify Functions

  1. Sign up for a free Netlify account
  2. Create a new site from the serverless-api folder
  3. Add your GitHub PAT in Site Settings → Environment Variables
  4. Deploy and use the functions endpoint

Option 3: Use Local Dashboard

  1. Open your local dashboard at file:///Users/hmoses/monocle-pr-github-dashboard/index.html
  2. Enter your GitHub PAT directly (stored in browser localStorage)
  3. Use immediately without any server setup

Why Serverless Backend?

Blockcell is a static file hosting service, perfect for HTML, CSS, and client-side JavaScript. However, to keep your GitHub PAT secure, we need a server-side component that can:

  • Store your PAT securely as an environment variable
  • Make authenticated requests to GitHub on your behalf
  • Return data to the dashboard without exposing credentials

This architecture ensures your PAT is never exposed in the browser, making it safe to share the dashboard with your team.
